## ✨ Funcionalidades

- 🔐 Login com validação simples
- 📋 CRUD completo de tarefas
- ✅ Marcar tarefas como concluídas
- 🗑️ Remover tarefas com animação
- ✏️ Editar tarefa com duplo clique
- 🔎 Filtros:
  - Todas
  - Pendentes
  - Concluídas
- 📊 Contador dinâmico
- 🧹 Limpar tarefas concluídas
- 💾 Persistência com LocalStorage (por usuário)
- ⌨️ Adicionar tarefas com ENTER
- 🎨 Interface moderna (estilo app)

---

## 🛠️ Tecnologias

- HTML5
- CSS3 (Glassmorphism + animações)
- JavaScript (Vanilla JS)
- LocalStorage API
