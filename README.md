# TaskFlow

Aplicação web de gerenciamento de tarefas desenvolvida com JavaScript.

## 🚀 Funcionalidades
- Adicionar tarefas
- Marcar como concluída
- Remover tarefas
- Filtro (todas, pendentes, concluídas)
- Contador de tarefas
- Persistência com localStorage

## 💻 Tecnologias
- HTML
- CSS
- JavaScript

## 🎯 Objetivo
Projeto desenvolvido para praticar manipulação de DOM e lógica de programação.
